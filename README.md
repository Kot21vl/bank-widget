# Bank Widget

## Описание
Проект виджета отображения банковских операций для клиента. Обрабатывает и маскирует данные о банковских картах и счетах.

## Установка
```bash
git clone https://github.com/Kot21vl/bank-widget
cd bank-wiget
poetry install
